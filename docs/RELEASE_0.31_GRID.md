# 0.31 / firmware-grid-1

[简体中文](RELEASE_0.31_GRID.md) · [English](RELEASE_0.31_GRID.en.md)

2026-10-22，固件管理界面的小版本更新。

- 左侧改为两列紧凑卡片；图标在上、名称在下。八款正式固件同屏显示，实验固件展开后按行吸附滚动。
- 顶部操作顺序为：刷新 SD → 显示/收起实验固件 → 安装该固件。选中已安装身份时显示“重新安装”。
- 点卡片只更换选择；右侧继续展示当前运行固件、安装条件与校验详情。安装禁止条件和自动 V15 中转流程未改动。
- M-VAVE、SLOOP、Baud Girl 使用发布者原标志；其余为本项目按对应界面风格绘制的像素图标。来源与许可见 [图标声明](../licenses/firmware-icons/NOTICES.md)。
- 未匹配支持目录的文件使用中性图标，长文件名在卡片中省略，右侧显示详情。

![固件管理界面（离线模拟）](../assets/screens/firmware-management.png)

验证：ESP-IDF 5.4.2 构建通过；UI 回归覆盖 266 次路由切换、256 个画面，包括正式/实验卡片、滚动定位、选中不触发安装、顶部按钮顺序和实际安装目标对应关系。13 项首装工具测试与 18 项 SD 工具测试通过。字体检查通过，未增加缺失字形。

应用镜像：2,477,024 字节，SHA-256 `60f96ef8782f862f3e3b865ba27914de195497fee2e519c614effdf2e22af20b`。

最新安装包为 [Releases 中的 M1n1Le55-0.31-grid-1.zip](https://github.com/ZzpsS/M1n1Le55/releases/tag/v0.31-grid-1)。版本号仍为 0.31，通过修订号区分新界面。仓库仅保留构建所需源码和使用说明，测试、打包与素材生成工具不随开源目录分发；上述验证记录描述发布前的检查结果。安装包精简不改变三份烧录镜像。

## 2026-10-22 实机升级记录

- 测试对象为一台已安装 `0.31 / recovery-1` 的原版 Tab5，P4 v1.3；不是新的出厂设备。
- `app-update` 检出旧引导程序与本包不同，在写入前停止。独立读回确认分区表与新包完全一致后，使用本包的 `first-install` 模式更新引导程序、分区表和应用，烧录摘要校验通过。NVS 分区未写入，C6 与 FM-1 固件未更新。
- 重启后诊断返回 `M1n1Le55 / 0.31 / firmware-grid-1`，分辨率 1280 × 720。四个主页面切换与返回固件管理页通过；SD 已挂载，读取到 10 个固件包。
- FM-1 USB 连接正常，身份仍为 `FM-1_916`；本轮未请求 FM-1 安装或音乐参数写入，校验期间错误帧和参数写入计数均为 0。

若旧版升级时出现 `Device bootloader/partitions differ`，表示应用更新模式没有写入任何内容。对于本项目同一分区布局的旧版，可按[新玩家说明](GETTING_STARTED_0.31.md#2-首次安装到-tab5)使用完整包的首装命令升级；分区布局不确定或来自其他系统时，应先按该系统的方法备份所需数据，不要强行只刷应用。

本轮验证覆盖烧录、启动与诊断页面切换，未确认物理触摸、声音表现或各 FM-1 固件迁移路线。新设备首装与各硬件批次的验证范围沿用新玩家说明中的限制。首页配图继续采用指定的离线模拟截图，原始设备日志留在本地，不进入公开目录。

## 硬件与功能范围

| 项目 | 当前范围 |
| --- | --- |
| 主板 | 原版 Tab5，P4 16 MB Flash / 32 MB PSRAM；非通用 P4 板 |
| P4 镜像修订 | v0.1–v1.99；应用 eFuse block 版本 ≤0.99 |
| 屏幕 | 代码包含 ILI9881C/GT911、ST7123、ST7121/ST712x；实机记录仅覆盖 ST7121 / P4 v1.3 |
| C6 | 不随本包烧录；BLE 要求兼容 ESP-Hosted，已有历史记录为 C6 1.4.1 |
| FM-1 安装 | 只允许内置目录的固定包；未知版本不能靠改名放行 |
| SD | FAT32；挂载失败需重启，无自动格式化或热插拔恢复；准备工具仅支持 Windows 盘符根目录 |
| 原厂备份 | 当前 155 字节音色；不是全预设或整机备份，没有触屏一键还原 JSON |
| 采样 | Open app protocol 4/FM1S；历史实测来自 V913 实验固件，不能推广至全部固件 |

精简发布提供中英项目介绍、新玩家说明与构建文档；固件 UI、功能和烧录镜像与本修订一致。全新设备首装、自动 V15 中转、多屏幕批次、C6 差异和断电恢复仍需实机验收。
